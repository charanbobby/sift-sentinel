Narrator

An E01 disk image goes in. [beat]

A fast skim model — Gemini Flash-Lite — scans for candidate paths where persistence typically hides: Run keys, scheduled tasks, startup folders.

A reasoning model — Claude Sonnet — orders a dependency-aware tool plan. You can't run RegRipper on a hive you haven't extracted, so the plan says: icat first, then regripper.

Gates run structural invariants. If the plan passes, gates issue a capability token — a scoped permission slip.

EXECUTE calls the MCP server — five typed forensic tools running the real SIFT toolchain. Every tool's output is split: raw bytes to the integrity ledger, parsed fields to the agent.

INTERPRET synthesizes typed findings with DFIR classification. CRITIC validates every finding with thirteen deterministic rules.

Out comes findings.json, plus a tamper-evident audit trail.

Narrator

At a glance, this reads "LLM → tools → LLM → checker." Standard agent pattern. What's new lives in four places.

Pillar 1

The Critic is deterministic — thirteen Python rules, no second LLM. Most agent frameworks review an LLM's output with another LLM, which rubber-stamps the same positive-finding bias. Our Critic is stress-tested against a published no-persistence scenario: the pipeline must return an empty findings list on a case where an attacker wasn't there. [beat] That's the test.

Pillar 2

In DFIR, the adversary authors the evidence. A filename, a registry value, a document body can carry a prompt-injection payload. The splitter routes raw bytes to the integrity ledger and parsed, sanitized fields to the agent. By design, the attacker's payload never reaches the LLM's context.

Pillar 3

Capability tokens bound to the specific plan hash. If the plan changes, every outstanding token dies. You can't replay yesterday's permission for today's plan.

Pillar 4

The audit ledger is a linear hash chain. Each entry embeds the SHA-256 of the one before. The ledger lives outside the case folder — because a process that writes evidence and the hashes that attest to it is self-attestation, not audit.

Production this scene is the submission's pitch. Slow down, use the beat labels as visual transitions — a small title card flashes for each Pillar label.
Emphasis "adversary authors the evidence" is the money line for Pillar 2. Hit it hard. Consider a sound sting here.
2:45 → 3:20 Scene 4 Where it runs — and what we're honest about 35s

Narrator

Deployment is deliberately honest. The orchestrator and the MCP server run in separate containers over an internal HTTP MCP bridge. Capability tokens are application-layer routing — not a cryptographic sandbox. A container escape or compromised runtime would still be outside the prototype boundary.

That's why Pillar 2 — the evidence splitter — is the real injection defense. If injection never reaches the agent's context, the hijack never happens in the first place.

The integrity ledger lives outside the container, on a separate volume. The container can't silently rewrite its own audit trail.

Production the honesty beat earns credibility with security-aware judges. Don't skip it — judges are conditioned to hear overclaim in hackathon videos; the caveat calibrates expectations.
Lower-third optional: "application-layer routing ≠ cryptographic sandbox" as a graphic overlay during the first two sentences.

Watch. The agent quotes a registry key — [pause] — that doesn't exist in the raw tool output. Rule R_02 — no invented text — fires. The Finding is quarantined before it reaches the report.

This is the load-bearing claim of the submission: invented text cannot pass the Critic, because R_02 is thirteen lines of Python, not another LLM's opinion.

today

R_02 catches it. CRITIC escalates to human_review. The run stops, the ledger records the attempt, and the case folder never gets the bad Finding.

next

The shipped build routes most Critic failures through a bounded retry — repeat guard blocks sycophantic duplicates, fresh context clears stale state, PLAN regenerates with a corrective instruction. Three of the thirteen rules always escalate; the rest retry.

Either way: no hallucinated evidence survives the Critic.
